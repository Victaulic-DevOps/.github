# Organization GitHub Standards

This repository provides shared GitHub assets and standards that are available across repositories within the organization.

The purpose of this repository is to centralize developer experience and governance-related resources, helping maintain consistency, reduce duplication, and simplify repository management.

## Current Contents

### Pull Request Template

This repository currently maintains the organization's standard Pull Request template.

Repositories that do not define their own pull request template will automatically use the template provided here. The template helps ensure pull requests include:

- Change summary
- Jira work item references
- Testing and validation details
- Deployment considerations
- Reviewer-relevant information

## Repository Purpose

This repository serves as the central location for organization-wide GitHub standards and shared assets.

Examples include:

- Pull Request templates
- Issue templates
- Security policies
- Contribution guidelines
- Support documentation
- Workflow templates

By maintaining these resources in a single location, the organization can provide a consistent developer experience across repositories while reducing maintenance overhead.

## Ownership

This repository is owned and maintained by the DevOps team.

## Change Management

Changes to shared templates and standards should be reviewed by the Victaulic DevOps-CoE team before being merged, as they may impact multiple repositories across the organization.
